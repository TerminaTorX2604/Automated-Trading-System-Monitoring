# Automated Trading System Monitoring and Risk Alert Framework

## Overview

This project simulates the monitoring of automated trading workflows by validating incoming market data and generating alerts for operational issues.

The framework performs basic production-style checks including missing prices, stale market data, negative prices, and unusually large price movements.

The objective is to demonstrate how automated monitoring can improve visibility into trading system health and reduce manual operational effort.

## Features

- Market data validation
- Missing value detection
- Negative price detection
- Stale data identification
- Large price movement alerts
- Alert logging

## Technologies

- Python
- Pandas

## Input

sample_market_data.csv

## Output

Console alerts identifying operational issues requiring investigation.
